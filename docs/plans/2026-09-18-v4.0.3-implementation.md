## Global Constraints

1. Every PR and every fix reviewed by `mcp-dev-servers-update-cc-template` at the exact sha in a detached worktree. Task PRs stack onto `v4/0.3`, true merges, no rebases; release PR `v4/0.3 → main`; tag on the merge commit.
2. All commits in worktrees. Implementers run only the suites their task touches, in the FOREGROUND (`bash scripts/test-hooks.sh > <log> 2>&1`, timeout 600000; `bash scripts/test-server.sh` after `bash server/install.sh` in the worktree; `bash scripts/verify-template-consistency.sh`). Never background a suite; never run `test-hooks.sh` concurrently with another suite or gate (shared gate dir).
3. Every file LF (`git diff --check`). A root hook change is mirrored to `user-level-reference/hooks/` in the same commit (check 21a); `HOOKS_NO_MIRROR` hooks have no mirror by design.
4. Every fix ships with the test that fails without it; RED observed first (state the failing line in the report), then GREEN; two-sided fixtures.
5. Derived, never hard-coded, except where the expectation IS the decision (the closed status tuple in Task 2 is such a decision).
6. A check's passing output is distinguishable from its null case; a verify line's expected end state is stated per mode.
7. Second-instance rule: after fixing a pattern, grep for its other copies and pin them together; list them in the PR body.
8. Stage NAMED paths only — never `git add -A`, `git add .`, `git commit -a`. Never push. Never create `.claude/git-guard-off`. No `git stash`. Commit with `git commit -F <msgfile outside the repo>`; the message ends with the two attribution lines the controller supplies.
9. The acceptance rule for any new assertion (reviewer): a one-line change to the production code must be able to make it fail. If not, it is not a check — reduce or drop it and say so.
10. `run-gate.sh` and `git-cmd.sh` carry standalone copies of `gc_gate_dir`; the consistency script asserts the copies agree — change both.

- [ ] **Step 2 (#12 fix):** in `git-cmd.sh` add:

```bash
# gc_script_body <segment> <cwd> -- when a segment runs a SCRIPT FILE
# (`bash|sh|source|. <path> [args]`, wrappers already stripped), print the
# first 16 KB of that file so the caller can feed it to the same matcher as
# extra segments. Depth 1 only: a script that invokes another script is a
# documented residual (v4.0.3 item 12). TOCTOU residual: the hook reads the
# file, allows the command, and nothing stops the file changing before bash
# runs it -- unfixable at this layer, stated so nobody believes the gate is
# stronger than it is. `[ -f ]`, never `[ -r ]`: a directory is readable.
gc_script_body() {
  local seg="$1" cwd="$2" tok path=""
  set -- $seg
  case "$1" in bash|sh|source|.) ;; *) return 0 ;; esac
  shift
  for tok in "$@"; do case "$tok" in -*) continue ;; *) path="$tok"; break ;; esac; done
  [ -n "$path" ] || return 0
  case "$path" in /*|[A-Za-z]:*) ;; *) path="$cwd/$path" ;; esac
  [ -f "$path" ] || return 0
  head -c 16384 "$path" 2>/dev/null
}
```
