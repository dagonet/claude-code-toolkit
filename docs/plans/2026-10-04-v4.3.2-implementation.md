# v4.3.2 — native pre-push hook + faster gate hooks Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Close the "script scanning is best-effort" gap for pushes with a native git `pre-push` hook. It refuses every create, update or delete of a protected branch, however the push was started. Also cut the per-call cost of `pre-commit-test.sh` on git-shaped commands (`git status --short`) by matching the fast-path triggers as words and writing the no-op record with one git call.

**Architecture:** Part P adds one tracked file, `hooks/git-pre-push.sh`, which is both the hook and its installer (`--install`). The installer writes a 7-line marked shim to `<git common dir>/hooks/pre-push` that execs the tracked file, so updates flow with every sync. Both setup scripts call the installer and never fail a bootstrap on it. A new consistency check pins "one source for the protected set" and "both bootstrappers install". Part F changes only `hooks/pre-commit-test.sh` (+ its mirror): two word-matched triggers in the S6 fast path, and a new `pct_note_noop` writer. Both keep fail-closed polarity: the fast path may only skip when the text provably holds no gated action, and the record stays a diagnostic that never gates.

**Tech Stack:** bash (Git Bash on Windows; bash 3.2-compatible syntax: no `${v,,}`, no `declare -A`; `printf '%(…)T'` only behind a version test), git ≥ 2.31 for `--path-format` (older git takes the existing fallbacks), PowerShell 5.1/7 for `setup-project.ps1`.

**Spec:** `docs/plans/2026-10-04-v4.3.2-design.md` (Parts P1–P6, F1–F3, Known limits, Q1–Q3). Read it first.

## Plan-level refinements of the spec

- **R-1 (P2, delete detection).** A delete is a stdin line whose **local sha** is all zeros (`*[!0]*` false). That covers SHA-1 and SHA-256 repositories without hard-coding a length.
- **R-2 (P3, the installer refuses a top-level without the hook).** The shim resolves `<top-level>/hooks/git-pre-push.sh`. A project bootstrapped into a **subdirectory** of another repository would get a shim that refuses every push, so the installer checks that `<top>/hooks/git-pre-push.sh` exists and otherwise does not install (exit 1, reason printed). This is the same top-level rule v4.3.1 G6 set for `PROJECT_CONTEXT.md`.
- **R-3 (P3, PowerShell installs through git's shell).** `setup-project.ps1` runs `git -C $TargetDir -c "alias.cct-pre-push=!bash hooks/git-pre-push.sh --install ." cct-pre-push`. The alias value holds no embedded quotes, because PS 5.1 mangles `"` inside native arguments. Git runs a `!` alias with its own `sh` from the top-level (outside a repository, from the `-C` directory), so the `bash` it starts is Git for Windows' bash, never WSL's.
- **R-4 (P3, setup output).** An install that does not happen is **not** added to the scripts' `warnings` arrays, so existing bootstrap rows that read the Warnings list stay valid. Each script prints one `Next step:` line after its summary instead.
- **R-5 (F1, patterns in variables).** The bracket patterns are held in variables (`pct_nw='[^[:alnum:]._]'`, `pct_sep='[[:space:];&|(){}!]'`). A literal `}` inside `${…//…/…}` would end the expansion.
- **R-6 (F2, old-git detection).** The one-call output is accepted only when it is exactly two absolute lines (`/…` or `X:…`). Anything else (a failing call, an old git, no repository) takes the existing `gc_gate_dir` path, so a record never lands somewhere new.
- **R-7 (F2, UTC without `date`).** `TZ=UTC0 pct_now …` sets TZ as a temporary assignment on the function call: bash exports it for the call and re-reads the zone. V2 pins the result under `TZ=JST-9`. If that row fails on the Windows target, **stop and report**; do not silently fall back.
- **R-8 (planning probe, Linux, 2026-10-04, at `5d3d789`).** The Task 1-2 hook and installer text, run against a bare remote: install 0; `main`, `HEAD:main`, `:main`, `--delete main`, a mixed push, a script push, a linked-worktree push and an old checkout were all refused; a feature push, a tag and `--no-verify` landed; the mixed push landed nothing; the shim had no CR. The F1 code gave walk=0 for `git status --short`, `echo "done. ok"`, `npm run publish`, `./build.sh`, `ls ..`, `echo done.`, and walk=1 for every gated shape in V2. `TZ=UTC0` on a function call gave UTC under `TZ=JST-9` (bash 5.2), and `${#}` under a local `LC_ALL=C` gave bytes (10 for `ls # — x`). The Claude-side gates refused the probe script itself until its verbs came from variables; that is the gap P1 names.

```bash
#!/usr/bin/env bash
# Native git pre-push hook (v4.3.2, design P2). Git runs this for EVERY push --
# typed in a terminal, run by a script, an alias, an IDE or a GUI client -- and
# hands it the refs that push will update, already resolved:
#   argv:  <remote name> <remote url>
#   stdin: <local ref> <local sha> <remote ref> <remote sha>   (one line per ref)
# A remote ref refs/heads/<b> with <b> protected is refused: create, update,
# force and delete (local sha all zeros) alike. Tags and every other ref pass.
# One refused line fails the hook, and git then lands NOTHING of that push.
#
# The protected set is the one hooks/no-push-main.sh enforces:
# gc_protected_branches (hooks/lib/git-cmd.sh) over the '- **Protected
# branches**:' line of the top-level PROJECT_CONTEXT.md -- CALLED, never
# re-implemented, so the two cannot drift (consistency check 69). No line, an
# empty value or a placeholder: main master (+ the remote's trunk). `none`:
# nothing.
#
# FAIL CLOSED: a missing or corrupt lib, no top-level, or a PROJECT_CONTEXT.md
# that exists but cannot be read refuses every push.
#
# The ONE deliberate escape is `git push --no-verify` (git skips this hook);
# .claude/git-guard-off is NOT honoured here. The server-side layer is a GitHub
# ruleset that requires a pull request (docs/templates.md).
#
# Not registered in settings.json: installed per clone as a shim in
# <git common dir>/hooks/pre-push by `bash hooks/git-pre-push.sh --install`.

gpp_install() { # [<dir>] -- Task 2
  echo "pre-push: not installed: installer not implemented yet" >&2
  return 1
}

if [ "${1:-}" = --install ]; then gpp_install "${2:-.}"; exit $?; fi

gpp_lib="$(dirname "$0")/lib/git-cmd.sh"
if [ ! -f "$gpp_lib" ]; then
  echo "BLOCKED: pre-push: $gpp_lib missing -- the protected branches cannot be read, push refused. Run /sync-template (hooks/lib/git-cmd.sh), or push deliberately with 'git push --no-verify'." >&2
  exit 1
fi
. "$gpp_lib"
command -v gc_protected_branches >/dev/null 2>&1 || {
  echo "BLOCKED: pre-push: $gpp_lib is present but corrupt (gc_protected_branches undefined) -- push refused." >&2
  exit 1
}

gpp_top=$(git rev-parse --show-toplevel 2>/dev/null)
if [ -z "$gpp_top" ]; then
  echo "BLOCKED: pre-push: cannot find the repository top-level -- push refused." >&2
  exit 1
fi
if [ -e "$gpp_top/PROJECT_CONTEXT.md" ] && [ ! -r "$gpp_top/PROJECT_CONTEXT.md" ]; then
  echo "BLOCKED: pre-push: $gpp_top/PROJECT_CONTEXT.md exists but cannot be read, so the protected branches are unknown -- push refused." >&2
  exit 1
fi
gpp_prot=$(gc_protected_branches "$gpp_top")

gpp_rc=0
while read -r gpp_lref gpp_lsha gpp_rref gpp_rsha; do
  case "$gpp_rref" in refs/heads/?*) gpp_b=${gpp_rref#refs/heads/} ;; *) continue ;; esac
  case " $gpp_prot " in *" $gpp_b "*) ;; *) continue ;; esac
  case "$gpp_lsha" in *[!0]*) gpp_what=push ;; *) gpp_what=delete ;; esac
  echo "BLOCKED: pre-push: $gpp_what of protected branch '$gpp_b' on remote '${1:-?}' refused (protected: $gpp_prot). Push a feature branch and open a PR; to push it deliberately: git push --no-verify." >&2
  gpp_rc=1
done
exit "$gpp_rc"
```

```bash
# gpp_shim -- the file --install writes to <git common dir>/hooks/pre-push. It
# never changes between releases: the logic lives in the tracked
# hooks/git-pre-push.sh, which every sync updates. A checkout without that file
# (a branch older than v4.3.2) is REFUSED -- fail closed -- with the way out.
gpp_shim() {
  cat <<'GPP_SHIM'
#!/bin/sh
# claude-code-toolkit pre-push shim -- written by `bash hooks/git-pre-push.sh --install`; rewritten on every install, do not edit.
h="$(git rev-parse --show-toplevel 2>/dev/null)/hooks/git-pre-push.sh"
if [ ! -f "$h" ]; then
  echo "BLOCKED: pre-push: $h is missing (this checkout predates v4.3.2, or hooks/ was removed) -- push refused. Merge the trunk into this branch, or push deliberately with 'git push --no-verify'." >&2
  exit 1
fi
exec bash "$h" "$@"
GPP_SHIM
}

# gpp_chain -- the line a user adds to a pre-push hook this installer must not
# overwrite. It saves stdin first: the user's own hook may read the refs too.
gpp_chain() {
  cat <<'GPP_CHAIN'
refs=$(cat); printf '%s\n' "$refs" | bash "$(git rev-parse --show-toplevel)/hooks/git-pre-push.sh" "$@" || exit 1
GPP_CHAIN
}

# gpp_install [<dir>] -- 0 installed, 1 not installed (reason on stderr). Never
# overwrites a foreign hook, never writes where core.hooksPath makes git look
# elsewhere, and never points a shim at a top-level without this file (R-2).
gpp_install() {
  gi_top=$(git -C "${1:-.}" rev-parse --show-toplevel 2>/dev/null)
  if [ -z "$gi_top" ]; then
    echo "pre-push: not installed: ${1:-.} is not a git repository -- run 'bash hooks/git-pre-push.sh --install' after 'git init'." >&2
    return 1
  fi
  if [ ! -f "$gi_top/hooks/git-pre-push.sh" ]; then
    echo "pre-push: not installed: $gi_top/hooks/git-pre-push.sh is missing -- the hooks must live at the repository top-level." >&2
    return 1
  fi
  gi_hp=$(git -C "$gi_top" config --get core.hooksPath 2>/dev/null)
  if [ -n "$gi_hp" ]; then
    { echo "pre-push: not installed: core.hooksPath is set ($gi_hp), so git ignores .git/hooks. Add this line to $gi_hp/pre-push yourself:"; gpp_chain; } >&2
    return 1
  fi
  gi_common=$(git -C "$gi_top" rev-parse --git-common-dir 2>/dev/null)
  case "$gi_common" in /*|[A-Za-z]:*) ;; *) gi_common="$gi_top/$gi_common" ;; esac
  gi_dst="$gi_common/hooks/pre-push"
  if [ -e "$gi_dst" ] && ! grep -qF 'claude-code-toolkit pre-push shim' "$gi_dst" 2>/dev/null; then
    { echo "pre-push: not installed: $gi_dst already exists and is not this toolkit's shim -- left untouched. Add this line to it yourself:"; gpp_chain; } >&2
    return 1
  fi
  if mkdir -p "$gi_common/hooks" 2>/dev/null && gpp_shim > "$gi_dst.tmp.$$" 2>/dev/null &&
     chmod +x "$gi_dst.tmp.$$" 2>/dev/null && mv -f "$gi_dst.tmp.$$" "$gi_dst" 2>/dev/null; then
    echo "pre-push: installed $gi_dst (runs hooks/git-pre-push.sh on every push)"
    return 0
  fi
  rm -f "$gi_dst.tmp.$$" 2>/dev/null
  echo "pre-push: not installed: cannot write $gi_dst" >&2
  return 1
}
```
