6. Expectations are derived, never hard-coded (variant key set from the template repo, commit from HEAD, classes from the manifest, exported tool names from the installed servers).

Capabilities, not versions: every new server surface the skill branches on gets a name in `v3.CAPABILITIES` (`superseded_keys`, `new_template_files_detail`, `missing_declared_keys`, `optional_absent_detail`, `template_verify`, `region_bytes_raw`) and `EXPECTED` in `server/tests/test_template_sync_capabilities.py` is updated in the same PR.

12. Process: author markdown and scripts with Edit/Write (never Bash heredocs); `git add <paths>` and `git commit -F <file outside the repo>` are separate tool calls; never `git add -A`/`.`; never push `main`; never create `.claude/git-guard-off`; never `git stash`.

- [ ] **Step 3: Rewrite `gc_matches_subcommand`**

Replace the function body at `hooks/lib/git-cmd.sh:1061-1085` with the walk as the sole authority (both the `GC_GIT_PRE` fast path and the `-C` pre-filter are deleted), with a per-verb mode. Three requirements the reviewer measured against the first draft of this step (spec item 10, F1–F3): (a) the state machine RESTARTS at every `git` token — in `first_only` mode a non-verb first token resets `seen_git`/`want_value` and scanning continues, it does not `exit`, so `git add -A && git commit -m x` still matches even when a caller hands the matcher an unsplit compound; (b) the git-token test is `tok == "git" || tok ~ /\/git$/ || substr(tok, length(tok) - 3) == "\\git"` — `tok ~ /\\git$/` degrades to `git$` on this awk ("\g is not a known regexp operator") and lets `notgit` open the walk; (c) surrounding `"`, `'`, `(`, `)` are stripped from a token before the git test (a dynamic regex built from a `-v sq="'"` variable, because the awk program is single-quoted in the shell and cannot contain a literal `'`), so the quoted-wrapper case only the deleted fast path caught (`bash -c "git commit -m x"`, `sh -lc`, `(git commit …)`) stays matched. The code below already includes (a)–(c):
```bash
# Verbs matched ONLY at git's real subcommand position (the first non-global
# token). `commit` is here because a bare `commit` operand after another verb
# (`log --grep commit`, `grep commit`) is a VALUE, not a commit (v4.0.1, item
# 10). `merge` and `push` are deliberately NOT here: "a bare operand anywhere
# after the globals refuses" is a documented tightening (see the A6.14 note
# above) and is pinned by test-hooks.sh.
GC_FIRST_TOKEN_VERBS=" commit "

gc_matches_subcommand() {
  case "$GC_FIRST_TOKEN_VERBS" in
    *" $2 "*) _gc_first_only=1 ;;
    *)        _gc_first_only=0 ;;
  esac
  # -v sq: a single quote handed in as a variable, because the awk program below
  # is itself single-quoted in this shell and cannot contain one literally.
  printf '%s\n' "$1" | tr ' \t' '\n\n' | awk -v verb="$2" -v first_only="$_gc_first_only" -v sq="'" '
    BEGIN { seen_git = 0; want_value = 0; wrap = "^[\"(" sq "]+|[\")" sq "]+$" }
    $0 == "" { next }
    function is_git(t) { return (t == "git" || t ~ /\/git$/ || substr(t, length(t) - 3) == "\\git") }
    {
      tok = $0
      gsub(wrap, "", tok)                  # quoted / parenthesised wrappers: bash -c "git …", (git …)
      if (tok == "") next
      if (!seen_git) {
        if (is_git(tok)) seen_git = 1
        next
      }
      if (want_value) { want_value = 0; next }
      if (tok == "-C" || tok == "-c" || tok == "--config-env" || tok == "--git-dir" ||
          tok == "--work-tree" || tok == "--namespace" || tok == "--exec-path" ||
          tok == "--attr-source" || tok == "--super-prefix") { want_value = 1; next }
      if (tok ~ /^-/) next                 # single-token global -- skip, not a match
      if (tok == verb) { print "MATCH"; exit }
      if (first_only) {                    # first non-global token was not the verb:
        seen_git = is_git(tok) ? 1 : 0     # this invocation is done; restart at the NEXT git token
        want_value = 0                     # (a compound segment: git add -A && git commit)
        next
      }
      next                                 # unrecognised bare word -- keep scanning (merge/push posture)
    }
  ' | grep -q MATCH
}
```

```python
def region_bytes_raw(content: str | None) -> int:
    """Byte length of the PROJECT-CUSTOM region body as it sits in the file:
    every byte after the BEGIN marker line's newline up to the first byte of
    the END marker line. No stripping -- this is the ONE definition shared
    with region.sh --bytes (v4.0.1, item 6). 0 for no region / empty region."""
    if not content:
        return 0
    b = content.find(core.CUSTOM_REGION_BEGIN)
    if b < 0:
        return 0
    nl = content.find("\n", b)
    e = content.find(core.CUSTOM_REGION_END, b)
    if nl < 0 or e < 0 or e <= nl:
        return 0
    line_start = content.rfind("\n", 0, e) + 1
    return len(content[nl + 1:line_start].encode("utf-8"))
```
