Replace `a6_inline_config()` at `:432` with:

```bash
# v3.0.3 item 1 — ARGV PREFIX SHAPE (finding 60). A gated git command is
#   [ENV...] git <globals> <subcommand> ...
# Every global before the subcommand is classified by ONE question: does it
# change what the command RESOLVES to? -c/--config-env (config), --git-dir/
# --work-tree (repo), --namespace (ref namespace — reads like a display option,
# moves the refs the merge decision is made from), --exec-path (which binaries
# run), --no-replace-objects (object resolution). Unknown globals are REFUSED:
# a future flag cannot silently join the allow side. -C is allowed because
# gc_repo_for resolves it. This is complete over the config channel: `git pull
# -c x=y` / `git merge -c` / `git push -c` all fail with `unknown switch` (git
# 2.55.0, measured by a consumer), so there is no after-the-subcommand position.
# Environment assignments before `git` (GIT_CONFIG=..., GIT_CONFIG_COUNT=...,
# `env X=Y git ...`) are refused for the same reason: they are config that the
# name comparison never reads.
a6_global_options() { # <segment> -> prints ok | refuse:<opt> | env:<VAR>
  local seg="$1" tok saw_git=0
  # shellcheck disable=SC2086
  set -- $seg
  while [ $# -gt 0 ]; do
    tok="$1"; shift
    if [ "$saw_git" -eq 0 ]; then
      case "$tok" in
        env) continue ;;
        *=*)  case "$tok" in GIT_*=*|*_GIT_*=*) printf 'env:%s\n' "${tok%%=*}"; return ;; esac; continue ;;
        git)  saw_git=1; continue ;;
        *)    continue ;;
      esac
    fi
    case "$tok" in
      -C)                 shift; continue ;;                       # resolved by gc_repo_for
      -C?*)               continue ;;
      --no-pager|-P|--paginate|--no-optional-locks|--literal-pathspecs|--no-lazy-fetch) continue ;;
      -c|-c?*|--config-env|--config-env=*|--git-dir|--git-dir=*|--work-tree|--work-tree=*|--namespace|--namespace=*|--exec-path|--exec-path=*|--no-replace-objects)
                          printf 'refuse:%s\n' "${tok%%=*}"; return ;;
      -*)                 printf 'refuse:%s\n' "$tok"; return ;;   # unknown global: fail closed
      *)                  printf 'ok\n'; return ;;                 # the subcommand
    esac
  done
  printf 'ok\n'
}
```

```bash
# v3.0.3 item 2 — see the fixture header in test-hooks.sh (A6.10) for the
# three categories and why `cd` is tracked rather than inert.
a6_clause_class() { # <segment> -> inert | tracked | mover
  local seg="$1" first
  case "$seg" in *'$('*|*'`'*) echo mover; return ;; esac        # substitution: can run anything
  case "$seg" in *'>'*|*'<'*) echo mover; return ;; esac          # redirection: can write .git/config
  first=$(printf '%s' "$seg" | awk '{print $1}')
  case "$first" in
    echo|printf|ls|pwd|true|:) echo inert; return ;;
    cd) echo tracked; return ;;
    git)
      if gc_matches_subcommand "$seg" checkout || gc_matches_subcommand "$seg" switch; then echo tracked; return; fi
      for ro in status log rev-parse diff show describe branch; do
        if gc_matches_subcommand "$seg" "$ro"; then
          case "$seg" in *' -u '*|*'--set-upstream'*|*' -f '*|*' -D '*|*' -d '*|*' -m '*|*' -M '*) echo mover; return ;; esac
          echo inert; return
        fi
      done
      echo mover; return ;;
  esac
  echo mover
}

Ten fixture rows added (see the message to the coder).
- Cleared by measurement, kept inert: `git status` does not rewrite the index across a run; `rev-parse` and `branch --show-current` have no write path.
- **(open-brain) Four substitution forms, not two:** `$(`, backtick, `<(`, `>(` — process substitution has neither of the first two and is 2 today. **And no clause is inert in a command containing a pipe:** `echo 'git merge …'` (prints, the false positive) and `echo 'git merge …' | bash` (executes) are the same clause; only what consumes stdout differs, which a per-clause classifier cannot see. Cheapest sound rule: a `|` anywhere → nothing inert, every segment scanned; `echo hello | bash` still passes. A clause is inert only if all four hold: allowlisted verb+flags, no substitution token, no redirection, no pipe. Twelve regression rows (four substitution, three pipe-to-shell, five compound shapes) must stay 2 and must NOT flip in delete-the-guard — they are caught by the scan, not the classifier.
