## Global Constraints

- KISS (standing user rule). Only what the item says.
- **Gate polarity is per hook.** Fail-closed guards refuse when unsure. Advisory hooks let the call through when unsure. A change must never flip a hook's polarity.
- Every new test is two-sided: the allowed shape passes, and the look-alike that must stay refused is refused.
- Every file is LF. Template `.claude/settings.json` stays byte-identical across the six variants; this plan does not touch it.
- The parser matrix (`scripts/test-hooks-parser-matrix.sh`) runs at release, because hooks are touched. Never run it beside a gate.
- Never print environment variable values. Run commands with `env -u TYPESAFE_API_KEY`.
- Experiments with `claude plugin` run only with `HOME=$(mktemp -d)` and `env -u CLAUDE_CONFIG_DIR`. Never copy credentials into a temp HOME.

## Review Focus

These are the inputs most likely to bite. Each is pinned by a test row in the task that owns it.
1. **Item 1:** a "read-only" chain that writes. Each of these must stay refused, with one row per shape (Task 1):
   - a redirect (`>`, `>>`);
   - `sed -i` / `--in-place`, or a sed script other than line-range printing;
   - `find -exec`/`-execdir`/`-delete`/`-ok`/`-fprint*`;
   - a pipe into a non-allowed command (`| sh`, `| tee f`, `| xargs`);
   - command substitution `$(…)` or backticks.
2. **Item 1:** a `cd` target that is not plainly inside the session cwd stays refused. That covers:
   - a relative path;
   - a `..` component;
   - `~` or `$VAR`;
   - a sibling whose name only shares a prefix (`/x/proj2` when the cwd is `/x/proj`);
   - an empty or missing cwd in the payload (Task 1).
3. **Item 2:** an advisory hook must not get `onFailure: "block"`. Pinned by check 83's two-sided rows (Task 2).
4. **Item 6:** a slash command of another plugin, or a bare `/<name>`, must not count as a toolkit skill start (R4). A `no` answer to an agent's question must not count as a correction, while a `no` that follows a plain statement still does (Task 3).
5. **Item 4:** a refusal text shared by two hooks must not be attributed to either; it counts as `other` (Task 3).

### Task 1: deny-hang-shapes — the safe subset of a leading `cd` (item 1)

**Files:** Modify `hooks/deny-hang-shapes.sh` (shape 3, around lines 102-150). Test: `scripts/test-hooks.sh`, in the deny-hang-shapes block.

**Rule:** today shape 3 refuses a leading `cd <dir>` that is followed by two or more commands. It now passes such a command only when **all** of these hold. Anything else keeps today's verdict (refuse).
- `DH_CWD` is non-empty.
- The `cd` target is one literal word. It is an absolute path (`/…`) with no `$`, `~`, glob characters or `..` component. It equals `DH_CWD`, or starts with `DH_CWD/`; compare with any trailing `/` removed from both.
- The rest of the command contains no `>`, no `<` other than inside a quoted pattern, no `$(`, no backtick, no `&` other than inside `&&`, and no `||`.
- Every command after the `cd` is joined by `&&`, `;` or `|`, and is one of the following:
  - `grep`/`egrep`/`fgrep`/`rg`;
  - `wc`, `ls`, `cat`, `head`, `tail`;
  - `sed -n '<range>p'`, where the range is a line number, `$`, `N,M` or `N,$`, single-quoted or bare, with no other sed flag or command;
  - `find` without `-exec`, `-execdir`, `-ok`, `-okdir`, `-delete`, `-fprint`, `-fprint0`, `-fprintf` or `-fls`.

Keep the existing refusal text. Add one sentence to the shape 3 comment saying why the subset is safe: Claude Code documents a compound command as prompt-free when every part qualifies, and a `cd` inside the working directory qualifies. Record the user decision (#47) there.

  - `deny-hang-shapes` (advisory);
  - `model-floor`, `jev-route`, `read-size-gate`, `enforce-delegation` or `agent-budget-warn` (fail-open by design);
  - any SessionStart, PostToolUse, Stop or SubagentStop hook.

**Facts (Claude Code docs, hooks page; changelog 2.1.295, 2.1.329):**
- `onFailure` goes on the individual hook handler object, next to `type` and `command`, with the value `"block"`.
- A failure is: the command cannot start, an exit code other than 0 or 2, or a timeout.
- Without the key the action goes ahead, and since 2.1.329 that is true in Code Mode as well.

- [ ] **Step 1: Write check 83 first, and see it red.**
  - Assertion: every PreToolUse handler in `hooks/hooks.json` and in the repo `.claude/settings.json` that runs a fail-closed guard has `"onFailure": "block"`, and no other handler does.
  - The fail-closed set is the list above, keyed by the guard name found in the command string.
  - Two-sided controls on temp copies:
    - a copy with the key removed from `gate-before-merge` is flagged;
    - a copy with the key added to `deny-hang-shapes` is flagged.
- [ ] **Step 2: Add the key** to the nine handlers.
- [ ] **Step 3: Validate the plugin manifest.** Run `HOME=$(mktemp -d) env -u CLAUDE_CONFIG_DIR claude plugin validate <worktree>`. Expect no error about `onFailure`. Remove the temp HOME afterwards, using the `"${D:?}"` form.

### Task 3: Counter fixes (items 4 and 6)

**Files:** Modify `scripts/self-review-count.py` and `scripts/fixtures/self-review/` (fixtures, `expected.json`, `expected-merge.md` if the shape changes).

1. **Slash-command skill starts.** A user row whose text contains `<command-name>/cct:<skill></command-name>`, where `<skill>` is a toolkit skill, adds 1 to `toolkit_use.skills[<skill>]`. A bare `/<skill>` or `/<other-plugin>:<skill>` does not count (R4). Count once per row.
2. **A "no" answer is not a correction.** A candidate is dropped when the most recent assistant message before it (in the same transcript) has text whose last non-space character is `?`.
3. **Refusal-text attribution.**
   - A table maps the toolkit's own refusal prefixes, the text right after `BLOCKED: `, to their hook. Build it by grepping `hooks/*.sh` and `hooks/hooks.json` for `BLOCKED: ` strings. Each mapped name must be a toolkit hook basename (R6).
   - A prefix found in two hooks maps to `other`.
   - `cct plugin files are missing` and `bash not found on PATH` map to `dispatch`.
   - It applies only when the token right after `BLOCKED: ` is not already a toolkit hook name.

  - an assistant statement followed by a user "no, wrong file", which is a candidate;
  - a `[command hook 4]: BLOCKED: No gate artifact found.` denial, which maps to `gate-before-merge`;
  - a prefix duplicated across two fixture hooks, which maps to `other`.
