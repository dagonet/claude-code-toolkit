## Harness and model changes since the last report

**Claude Code (2.1.330 to 2.1.332; the changelog gives no dates):**
- **2.1.331, plugins: `optionalDependencies` in a plugin manifest.** Newly possible: `cct` could name `cct-guards`, `cct-learning` and `cct-helpers` there. Whether an install then offers or restores them is not stated; worth one throwaway test (temp HOME), because the marketplace remove still drops every optional plugin.
- **2.1.330, agents: an agent with no model now inherits a subagent model fallback.** Check the user-level rule's sentence "otherwise it inherits the orchestrator's": it may no longer be exact. The rule itself (name the model) is unaffected.
- **2.1.330, skills: a skill with a `model` setting leaves subagents, forks and compaction on the session model.** No toolkit skill sets `model`; no change.
- **2.1.332, hooks: a new `PreSkillShellCommand` event** can refuse a skill's inline shell commands while it loads. Newly possible; the toolkit's skills carry no inline shell, so nothing to guard today.
- **2.1.332, hooks: long logs of a blocking or failing hook are now shortened.** The toolkit's refusal texts are short and the counter matches their start, so no change is expected; confirm with the first v7.0.1 counts.
- **2.1.330, permissions: `rm` at the root, the home folder, a top-level folder or the working folder now asks.** Redundant with nothing in the toolkit (it ships no `rm` guard); a new safety net for agents.
- **2.1.330, hooks: valid hook commands in settings files are no longer refused by Edit.** Removes a known friction when a sync edits `settings.json`.
- **2.1.332, rules: `CLAUDE.md` and rules are no longer resent after `EnterWorktree`.** Cheaper for harness-made worktrees; the toolkit's declared worktree location is unaffected.
- **2.1.331, marketplaces: managed `extraKnownMarketplaces` auto-update by default on or after 2026-11-30.** Applies to managed settings only; the toolkit pins by tag in user settings, so no change.
- **2.1.330 to 2.1.332, Code Mode:** many fixes (a subagent reported "stalled" after a 10-minute script, resume, long output). No toolkit rule depends on them.

**Models (source: platform.claude.com models overview, deprecations and API release notes, read 2026-11-26; the release-notes page was read only in part):**

- **Shipped files:** no setting, agent or hook names a retiring or deprecated model. The old ids appear only in the counter's own examples.
- **Prices and efforts as listed:** Fable 5.2 $8 / $40, Opus 5.5 $4 / $20, Sonnet 5.5 $2 / $10 per million tokens; default effort Fable high, Opus medium, Sonnet high, Haiku medium. Unchanged for the three tiers the first report covered; the Fable default is new here.
- **Cache reads:** the overview gives them as 2.5 % of the input price on Fable and 5 % on Opus and Sonnet 5.5. By that arithmetic a cached token costs the same on Fable as on Opus, and half that on Sonnet. A long main session on Fable therefore costs more than Opus mainly through its output, not its context. No rule changes; worth knowing when choosing the session model.
